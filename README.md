This project is a simple yet enhanced Core Java console application that demonstrates Object-Oriented Programming (OOP) concepts like classes, objects, constructors, and methods, along with user interaction, salary calculations, and formatted output. It calculates the gross salary (base + bonus) and the net salary (after tax deductions) for an employee.

Features:
Uses class, constructor, and methods
Calculates gross and net salary
Takes user input using Scanner
Implements bonus and tax calculation logic
Displays a well-formatted salary summary
Demonstrates encapsulation and clean code structure

Concepts Used:
Object-Oriented Programming (OOP)
Encapsulation
Constructors and Methods
Scanner (User Input Handling)
Arithmetic Operations
Conditional Logic
Formatted Console Output


How to Run:
Open any Java IDE (VS Code) or terminal.
Save the file as Employee.java.

Compile the program:
javac Employee.java


Run the program:
java Employee


Enter values when prompted.
